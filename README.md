KinoVision

KinoVision is a wearable, gesture-controlled, vision-based smart home automation system that combines ESP-NOW, MQTT, and AI vision recognition for intuitive appliance control.

System Overview:
Gesture Wristband (XIAO ESP32-S3 + MPU6050)
ESP32 Home Hub with Relay
Vision Pendant (Adafruit Memento)
OpenAI Vision API Integration

Features:
Gesture-based device selection
AI-powered appliance identification
Modular communication architecture
3D printed wearable enclosures

Repository Structure:
/firmware – All source code
/hardware – PCB, schematics, BOM
/diagrams – System flow and block diagrams
